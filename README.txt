GITHUB PAGES – KURZANLEITUNG

1. index.html, style.css und script.js in den Hauptordner (Root) deines Repositorys laden.
2. Repository > Settings > Pages öffnen.
3. Deploy from a branch wählen, Branch main und Ordner /(root) auswählen, Save.
4. Die HTTPS-Adresse öffnen und die Kameraberechtigung erlauben.
5. Auf „Kamera starten“ tippen.

Die QR-Codes enthalten nur die Kennungen EG-001, EG-002, EG-003, EG-004 und OG-001.
Die Zuordnung zu den gesprochenen Standortnamen steht in script.js im Objekt locations.
Die Etiketten sind Testbeispiele und müssen den tatsächlichen Orten angepasst werden.

Hinweis: Die QR-Erkennungsbibliothek wird von einem CDN geladen; Internet ist zum Laden erforderlich.
